# AegisScan AI — Demo

> See risk before it strikes.

AegisScan AI scans your environment with on-device AI, scores hazard risk,
and orchestrates alerts to the right people.

**Model ID:** `aegisscan/hazard-vision-v0.1`
**Version:** 0.1.0-demo

## Quick start (local)
```bash
git clone https://github.com/<you>/aegisscan-demo.git
cd aegisscan-demo
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python app.py
# open http://localhost:8000
